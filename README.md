# 蓝脉航路 2.2

浏览器单机商队经营游戏。安排商路、船只与货本，自动跑商，查看利润并决定扩张。全部货币使用 CR。

当前版本 **2.2.0**，存档结构 **v33**。包含四座港口、四类货物、六种船型、六十五项科技与100级公司成长，支持真实时间经营、四槽存档、科技研发、市场情报交易、固定窗口报告与风格化星图。

商路按原配置持续经营。临时缺货、需求暂满或货量不足以覆盖运费时保留任务、船只和货本，停靠等待供需恢复后自动续跑；只在完整货本无法支持盈利航次或玩家主动结束时解除。已锁定航次完整返港结算后释放预算和船只，无在途航次时立即释放。已结束任务保留历史与统计，玩家可用空闲船重新派遣，不自动新建任务或复投利润。

基础三港大部分供需扩大为原来的 4 倍，主星矿石需求提高到 96，工业原料供需提高到 360。仍每 60 秒恢复上限的 50%，旧档保留现有库存与在途账目，从下一次刷新使用新恢复额度；初始单船商路已验证连续满载运行 15 分钟。固定策略的扩容前后结果见 [供需扩容对照](docs/2.1/供需扩容对照.json)。

经营调度在同一区域切换航运任务与科技研发。100级公司每5级一阶，每阶开放3–4项科技的研发资格，共 65 项，属性单次提升为 1%–4%，完成研发后获得航速、载量、商路净利、船队扩容、功能或船型能力。航运科技统一在经营研发中作为一种类型，包含基础船体和进阶船型解锁；可按航运科技、航速、载量、收益、船队扩容和功能筛选。科技树按每5级分段向下延伸，桌面分支按宽度分列，手机单列；前置箭头、阶段跳转和关系详情支持定位。研发完成后保留完整卡片、原位置和原尺寸，标记“已研发”；分类展示全部项目，另列已研发与待研发数量，完成进度和累计加成继续更新。船只页保留船队、采购和投资比较。旧经营方案及补派入口已移除。

派遣后每项航运任务集中在一张可展开卡片：卡头显示线路、运行状态、已完成趟数与任务净利，展开后查看各船的真实航段进度、抵达或返港时间、货本和最近结算，并直接调整或结束任务。多任务切换只展开当前查看的一项，倒计时刷新保留操作焦点。

新局提供简短开场与最多五步软引导，可随时跳过；旧档不重播。首航预填真实满载货本，显示返港回款倒计时和已到账净利。引导结束后按实际经营状态提示第二条商路、升级与首次探索资金，本级资金备齐后可提升一级；派遣中的货本建议由玩家点击应用，定时刷新保留输入与焦点。新局仅有1个船位，逐级积累并完成每5级的突破；Lv.9依次研发云帆船体和核心船位规划，再购买第二艘船并备齐满载货本。固定跟随建议策略约18秒首航回款、8分35秒首次升级、181.17分钟第二商路出发、587.92分钟首次开港，见[当前前期节奏](docs/2.1/科技树前期节奏.json)。公司发展、科技研发与探索动态保留在经营页。

公司Lv.24研发新港勘察后探索星云工厂，费用 360 CR；公司Lv.57研发远域勘察且工厂开放后探索极光原料港，费用 1,800 CR。两者都使用空闲船，完整往返后才开放，不赠船或 CR。工业原料商路提供远距离、高吞吐的重载场景。星图港口详情能直接打开经营配置。

迅鸥轻舟从开局具备采购资格，采购还需空余船位；云帆与长鲸分别在Lv.6、Lv.10完成船体研发后开放，船坞与市场分别需Lv.15船队管理、Lv.20市场通讯研发。进阶船研发资格在Lv.35、52、71开放，研发费用分别为128,200、336,000、1,305,000 CR，购船另付。全部科技累计航速+30%、载量+45%、商路净利+30%，下一次出发应用，在途时间和金额保留。基础船位从1增加至满级30，11项船队扩容另加15个，最终45艘。

科研费用共用公司满编价格曲线，按所属等级的普通费用 × 阶段N × 效果权重 × 核心系数取整到100 CR，8个核心系数为1.75–2.5，其余为1；全部65项共9,389,600 CR；已完成项目不补扣费用。公司共100级、20阶，Lv.5、10…95将升级按钮改为突破；突破费用是进入本阶第五级的普通费用乘N。N从2开始，每次增加0.5，第一次4,200 CR，最后一次1,951,400 CR。普通升级或突破均只升一级，发展路线只显示当前阶的5级；Lv.100满级。普通费用沿之前接受的价格锚点递增，升级与突破共16,738,900 CR。满编成长策略已通过真实贸易支付全部费用，完成100级、65项研发与45艘船约需228.5小时，见[科技树与核心研发](docs/2.1/08_科技树与核心研发.md)；每阶段最大船位、独立投入和共享供需收入都已实测。完整规则见[百级公司与五级突破](docs/2.1/06_百级公司突破.md)和[科技研发](docs/2.1/04_科技研发.md)。

经营报告默认显示统计期累计净利与最近 15 分钟效率，航次数和装载率同时可见。5 / 15 / 60 分钟筛选收进线路详情，仅调整详情的比较时段；按本分钟及此前 4 / 14 / 59 分钟计算，并注明实际覆盖时间。累计统计独立于逐笔留存；旧档从迁移时的账本时间开始统计，不补造早期记录。

## 本地运行

```sh
npm ci
npm run dev
```

打开 `http://localhost:4173/`。构建使用 `npm run build`，产物为 `dist/`。

## 检查

```sh
npm test
npm run check
npm run check:scene-assets
npm run test:production
npm run release:seal
npm run check:release
```

生产包浏览器回归执行 Chromium 与 WebKit 宽窄屏的真实玩家操作，使用独立端口与测试浏览器上下文，不读写日常试玩存档。浏览器需预先安装 Playwright 对应运行时。

`npm run simulate:early` 从真实新局跟随首航、第二商路、攒足资金和首次探索建议，加 `-- --write` 更新前期节奏记录。此实验每秒查看，时间不包含阅读与操作耗时。`npm run simulate:investment` 固定实验资格和随机种子，比较 3 / 6 / 12 船、每 60 / 300 秒查看时的持续经营，以及实际研发并购买进阶船与同预算基础船。加 `-- --write` 更新 [当前投资对照](docs/2.1/科技树投资对照.json)，共同实验资格需要实际支付完整前置链；船位、采购和货本分开计算。商路稳定性调整前后的独立对照保存在 [商路稳定性对照](docs/2.1/商路稳定性对照.json)，旧投资实验结果保留为对应旧规则的记录。它是固定策略实验，不是新局成长或最优收益承诺。`npm run simulate:growth` 使用三港三船策略检查成长；持续任务不重派，探索仍需释放原船并完整返港；`-- --with-research` 实际研发全部 65 项科技并使用加成，不采购进阶船。`npm run simulate:tech -- --write` 记录各核心研发前的最大船队、真实共享供需净利与费用积累比值。`npm run simulate:pricing` 固定不同阶段的资格与科技，通过真实购船、探索和派遣测量各级60分钟收入，并记录普通升级与突破的实际积累时间；实验资金只用于模拟，不代表新局积累。

`npm run assets:scene` 可通过本机 Chrome 重建原创资产。`npm run release:seal` 验证后生成当前版本的本地 ZIP、清单与校验值，不提交 Git、不部署。

v32及更早存档的18级公司按已具备的科技资格映射到百级，v27及更早的6级公司先对应原18级阶段；v32原文备份为`startrader_save_before_v33_槽位`，重复读取不再转换，迁移前另存原始备份，原港口、船型、科技及在途航次保留。v28 升至 v29 会删除旧方案并保留运行任务与账本，补齐已开放能力的研发，不赠送属性加成。v29 升至 v30 仅补空的情报收藏，已开放港口的信息免费展示。v30 升至 v31 将已研发的属性科技展开为对应完整分组，保留原加成与在途快照，并备份原文。v31 及更早已获得的扩容资格在 v32 转为已完成研发，不扣款、不赠船；v31 原文另存备份。所有存档的基础船位采用当前平衡表，已有船只、任务和货本保留；超出新上限时仅禁止添购，现有船继续经营。损坏或未来版本存档不会静默覆盖。经营首屏后可提前准备星图资源，进入星图才创建 3D 场景，加载层等待真实首帧，失败可重试或回到经营。
