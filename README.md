# 蓝脉航路 2.0

浏览器单机商队经营游戏。安排商路、船只与货本，自动跑商，在任务列表管理经营，回来查看利润并决定扩张。全部货币使用 CR。

无法继续的任务自动解除，已锁定航次完整返港结算后释放预算和船只；无在途航次时立即释放。市场恢复后由玩家重新派遣，只有同任务在途货本暂时占用且仍能盈利时等待回款。

当前版本 **2.0.0**，存档结构 **v26**。包含三座港口、三类货物、六种船型、三项航运科技与六级公司成长，支持真实时间后台经营、四槽存档、线路账本与风格化星图。

新局提供简短开场与最多五步软引导，全程可跳过、自由操作，不赠资金或船、不加速；旧存档不重新弹出。

公司二级后在星图发现探索信号，选择空闲船与已开放源港，支付 360 CR 完成去程、勘察和返程后解锁星云工厂商路；探索不赠船或 CR，旧档已开放港口保留。

三种基础船初期可购，三项科技分别解锁一种进阶船的可购资格，研发费用为 3,000 / 9,000 / 27,000 CR，购船另付。已完成研发与现有船只继续保留。

## 本地运行

```sh
npm ci
npm run dev
```

打开 http://localhost:4173/。构建使用 `npm run build`，产物为 `dist/`。

## 检查

```sh
npm test
npm run check
npm run check:scene-assets
npm run build
npm run check:release
```

`npm run simulate:growth` 以固定随机种子（默认 42，可指定 `--seed=<整数>`）模拟真实停用、返港、派船探索和三港扩张，每秒模拟玩家检查供需、在盈利且货本足额时主动补派，并保留补派本金；加上 `-- --with-research` 比较先投入科技再升级的策略。两者都不采购进阶船，不代表无人值守或离线收益；游戏不会自动恢复已结束任务。`npm run assets:scene` 可通过本机 Chrome 重建原创资产。浏览器回归用例使用独立端口，不读写日常试玩存档。

旧玩法代码与历史方案已退出仓库产品目录。现有经营存档在转换前自动保留原始备份，损坏或未来版本存档不会被静默覆盖。游戏规则见当前文档，清理前代码资料备份存放在项目外。

经营首屏完成后，星图资源可在空闲时提前准备；进入星图时才创建 3D 场景，通用加载层等真实首帧绘制后关闭。优化保持原有分辨率与视觉，失败时可重试或回到经营。

技术：Vite、原生 JavaScript、Three.js、LocalStorage。许可证：ISC。
