# 场景资产 · 第三版

本目录包含项目原创舰船模型及游戏内使用的透明展示图。建模源保留在 `js/ui/ShipModelFactory.js`，制作入口 `scripts/art/ShipAssetFactory.mjs` 复用同一实现。

## 舰船

- `ships/shuttle.glb`：短机身、双引擎、小型三角翼与一体座舱。
- `ships/freighter.glb`：外露承载骨架、六组模块货舱、前置驾驶室。
- `ships/clipper.glb`：细长舰体、独立引擎舱与纵向散热鳍。
- `ships/galleon.glb`：多层甲板、高位舰桥、侧舱与六具推进器。

对应同名 WebP 为 1120×640 的透明正交展示图，另有同尺寸的 `.shadow.webp` 停泊阴影，远程检视不显示地面阴影。GLB 坐标以 +X 为舰首、+Y 为上方；尺度仅用于美术，不对应游戏航程或船舱数值。每个模型合并为最多 8 个材质组，包含金属、装甲、玻璃、涂装和工作灯。未包含骨骼、碰撞体或动画。

航行阶段补充 `engineSockets` 喷口位置与半径元数据，四种船分别有 2、2、3、6 个喷口。实时星图从同一建模源创建舰体，按船型缓存几何，喷焰合为实例化绘制；不在运行时下载或解析 GLB。舰体展示图与阴影沿用第三版光照，航迹和进出港提示由实时场景绘制。

## 港口

`ports/` 包含 13 张 640×640 透明主体图：空间站、矿区、太阳主星与十类产业行星。空间站和矿区复用星图模型；行星复用星图地表生成器。码头、机库与文字由游戏 DOM / SVG 组合。

## 重建与校验

```sh
npm run assets:scene
npm run check:scene-assets
```

重建使用已安装依赖和本机 Chrome，会启动临时本地 Vite 端口，并覆盖本目录中的生成资产与清单。可通过 `SCENE_ASSET_BROWSER` 选择 Playwright 的浏览器通道。没有联网获取模型、贴图或付费生成服务。运行游戏和普通生产构建无需执行资产重建，也不需要下载 GLB。

`manifest.json` 记录建模源和导出文件的 SHA-256、尺寸、字节数、三角面与材质组数，以及渲染浏览器版本。导出时执行 GLB 回读、有限顶点和光栅透明边界检查；校验脚本另核对来源哈希、文件头与大小预算。模型预算为 6,000 三角面 / 8 组材质，单张展示图小于 100 KB。不同 GPU 或浏览器版本可能产生细微光栅差异。

这些是项目内已校验的资产文件，未经过缺失的 `game-dev` CLI canonical package 流程。GLB 回读与浏览器核对不代表已在其他引擎完成导入验证。

## 来源与许可

舰船由本项目代码原创建模，港口源自本项目已有程序化场景；沿用项目声明的 ISC 许可。制作工具使用 Three.js（MIT）；反射环境由项目内的 `SceneLighting.js` 生成 HDR 半浮点数据并预滤波，不使用 `RoomEnvironment`、外部 HDR、第三方模型或纹理。游戏实际展示图仅加载当前所需资源。

## 第三版光照与材质

实时星图和离线展示共用 `SceneLighting.js` 与 `SceneMaterials.js`。主光、补光、环境反射和曝光保持一致；玻璃使用非金属、IOR 1.46 的涂层材质。星图仅在初始化和上下文恢复时生成反射环境，销毁时释放目标纹理；机库仍使用展示图，无新增实时 WebGL。停泊阴影在制作阶段从舰船模型投射并柔化，独立校验透明边界。

`docs/art/lighting-review.html` 提供四种舰船的滑杆对比；同目录 `lighting-before/` 保留上一版原创展示图作为对照，不进入游戏运行时资源。
