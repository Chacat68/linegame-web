# 百级公司与五级突破

当前规则：公司 Lv.1–100，每5级一阶，共20阶。Lv.5、10、15…95是突破关卡；Lv.100是最终满级。普通升级和突破都只能提升一级，不支持批量升级、跳级或跳阶。

## 突破费用与按钮

达到本阶第五级时，升级按钮改为“突破公司至 Lv.下一等级”，显示当前阶数、突破费用与计算依据。资金不足或触及首航货本储备时禁用并显示原因；突破成功后进入下一阶，按钮恢复为升级。

突破费用 = **升到本阶第五级的普通升级费用 × N**。这里的基数是 Lv.4→5、Lv.9→10等进入第五级的费用。N = **2 + 0.5 ×（当前阶数 − 1）**：第一次2倍，之后每次增加0.5，Lv.95最后一次为11倍。Lv.100不再收取突破费。

例如 Lv.4→5支付2,100 CR，Lv.5→6突破支付4,200 CR；Lv.9→10支付3,300 CR，Lv.10→11突破支付8,250 CR。突破含一次进入下一阶的升级，不再叠加下一阶的普通升级费。

普通升级价格保留之前接受的2,100–181,000 CR价格锚点，按科技资格在百级中的位置插值，向上取整到100 CR。突破费单独按上述倍率计算，因此突破后普通费用可以低于刚支付的突破费。Lv.1→100所有升级与突破共计 **16,738,900 CR**，购船、研发、探索与周转货本另行支付。

## 科技与前期引导

65项科技保留等级资格和单项效果，当前增加分支前置与核心研发，研发资格分散到100级，每个5级阶段3–4项。科技不会因升级或突破自动完成，已研发项目保留原尺寸的完整卡片并标记“已研发”。最终总加成保持航速+30%、载量+45%、商路净利+30%；科研共用阶段N与普通费用，8个核心另有系数，全部费用为9,389,600 CR，当前规则和验证见[科技树与核心研发](08_科技树与核心研发.md)。Lv.1基础船位1个，Lv.100基础30个，11项扩容另增15个，最终45艘。

关键资格：Lv.6云帆船体，Lv.9船位规划，Lv.10长鲸船体，Lv.15船队管理，Lv.20市场通讯，Lv.24新港勘察，Lv.35快速航路，Lv.52重载物流，Lv.57远域勘察，Lv.71联运调度。情报交易分别在Lv.20、Lv.50开放。港口仍必须完整探索返港后才能经营。

前期提示与公司按钮共用逐级校验和突破费用。首航回款前不推荐扩张；Lv.9完成付费船位研发后才允许添船，第二条商路须备齐采购和满载货本；首次探索前保护研发和探索的独立投入。

## 旧存档迁移（v33）

v32及以前的18级公司按旧等级可研发科技的最高新资格等级映射，保证已获得的资格不倒退。科技ID、已付费研发、现金、持有船、任务预算、市场库存与在途快照保留，不追加现金、飞船或研发奖励。v31及以前已有的扩容资格继续按原迁移规则保留。超额旧船继续经营，采购等待取得空余船位。

## 科研调价前的验证与经济记录

本节三个“百级公司”实验采用当时148,890 CR科研费用，保留为历史基线；调价后最新实验见[科技研发梯度定价](07_科技研发梯度定价.md)。

- [百级公司满编测算](百级公司满编测算.json)：全部100级，分别实际研究、采购基础与全扩容船队，支付完整周转货本，60分钟共享港口供需，保留两种混编策略的实际收益。
- [百级公司满编成长](百级公司满编成长.json)：真实初始1,000 CR与一艘轻舟，不外加资金，每级先研究、补满船位并划拨货本再升级或突破；探索停派原船并完整返港。
- [百级公司前期节奏](百级公司前期节奏.json)：跟随界面建议经营首航、第二商路、突破与首次开港。

满编成长策略完成100级、65项研发和45艘船，共8,972.33分钟（约149.54小时）。升级与突破16,738,900 CR、科研148,890 CR、采购51,274 CR、探索2,160 CR分别实际支付；全部级别均达到当级完整船位。末次突破在固定满编收入实验中约需778.57分钟积累。该结果是固定经营策略与当前真实共享供需的测算，包含供需等待，不代表所有船同时满载或最优策略。

跟随建议策略首笔回款仍为18秒，首次升级8分35秒；第二商路约142.58分钟，新港约447.33分钟开放。百级与突破拉长了中后期积累，原18级测算和文档保留为历史记录。

本地验证覆盖全部19个突破、普通指令无法绕过关卡、费用不足与首航储备、跨级和重复提交、旧档迁移一次性、任务与航次保持，以及宽窄屏的路线切换、按钮文字、焦点与刷新恢复。验证截图存于[百级公司验收截图](验收截图/百级公司/)；执行命令与最终结果见目录README。

最终验证：320项单测、`npm run check`、`npm run build`通过；两份经营生产回归在四种浏览器尺寸共88项通过。公司布局最后调整后，四种尺寸再次完整执行1→100级，共4项通过；手机突破公式可见，发展路线内没有水平滚动。日常4173试玩页已实际核对当前阶段和在途商路。
