# 科技研发梯度定价

科研与百级公司共用按阶段满编船队收入校准的普通费用曲线。65项科技的等级、前置、效果和船位保留，实际研发扣费、资金提示、船型完整投入与经济模拟统一采用新价格。

## 费用规则

**研发费用 = 所属等级的公司普通费用基数 × N × 效果权重，向上取整到100 CR。**

N与公司共用每5级阶段系数：N = 2 + 0.5 ×（阶数 − 1）。第1阶为2，第20阶为11.5。公司突破使用进入第五级的普通费用，科研使用科技所属等级的普通费用；科研不以已乘N的突破金额为基数。Lv.100使用终段181,000 CR，满级科研仍需付费。

| 科技类型 | 效果权重 |
| --- | --- |
| 航速、载量、收益 | 每增加1个百分点使用5%；+2%为10%，+4%为20% |
| 船队扩容 | 每增加1个船位使用15%；+2个为30% |
| 新功能 | 25% |
| 新船型 | 50% |

推迟到更高等级研究早期科技仍使用项目原所属阶段报价。公司升级、突破、科研各自支付；购船递增报价、完整周转货本、探索与情报单独投入。

Lv.35快速航路：29,300 × N5 × 船型50% = 73,250，取整为73,300 CR；该级公司突破费用142,000 CR，科研没有重复使用突破金额。Lv.100商盟泊位：181,000 × 11.5 × 两个船位30% = 624,450，取整为624,500 CR。

## 余额、存档与前期节奏

界面与指令共用科技报价；现金不足、前置未完成或扣费后低于首航货本储备时拒绝研发，并保留原账本。每项只收费一次，完成后卡片隐藏。存档结构保持v33；已研发科技、现金、船只及在途贸易/探索快照保留，不追加费用或退款。下一次出发才应用新增科技效果。

跟随前期建议的真实新局：首航回款18秒，首次升级8分35秒，第二商路约150.58分钟，首次新港约480.48分钟。支付公司135,050 CR、科研11,200 CR、第二艘船336 CR与探索360 CR，任务继续经营且货本保留。测算不包含阅读和操作耗时，固定策略不代表最优策略。

## 本轮实验与验证

- [满编收入与科研投入](科技梯度定价满编测算.json)：全部100级的基础与全扩容船队，实际支付科研、采购、探索与货本，共享供需经营60分钟。
- [真实新局满编成长](科技梯度定价满编成长.json)：逐级付费完成科研和满编后升级与突破，使用实际回款，不外加资金。
- [跟随建议的前期节奏](科技梯度定价前期节奏.json)：单船起步、付费扩容、第二商路和首次完整开港。
- [船型投资对照](科技梯度定价投资对照.json)：包含进阶船型和全部缺少前置科研的完整投入。

从1,000 CR与一艘轻舟起步，满编策略实际完成100级、65项研发和45艘船，共12,634.17分钟（约210.57小时）。逐级支付公司16,738,900 CR、科研7,320,800 CR、购船51,274 CR和探索2,160 CR；累计净利24,126,496 CR，期末自由现金210 CR与投入任务/在途的货本14,152 CR满足完整收支恒等式。每一级都采购至当级全部研发后的最大船数，并保留全船队周转货本。

全100级收入实验在已完成相同科技后与调价前的各级净利完全一致；调价增加真实成长所需的资金积累。最终45艘满编在所测较高收益混编策略中实际净利2,606.92 CR/分钟，全部研发与购船、探索、货本的完整投入7,388,141 CR。测算共享一份真实供需，包含等待，不将45艘同时满载作为收入假设。
