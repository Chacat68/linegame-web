# 经营 UI 信息密度矩阵

> 日期：2026-05-22  
> 范围：HUD、商业终端、星图详情、机库派遣 / 改装  
> 原则：全局下一步只由行动条承载；页面内部只展示本页面能解释或执行的局部状态。

## 1. 信息归属矩阵

| 区域 | 当前承载 | 结论 | 调整 |
|---|---|---|---|
| 行动条 `ActionGuideUI` | 当前行动标题、原因、执行按钮 | 保留 | 作为唯一全局下一步入口。 |
| HUD 当前航点 | 所属星系、政体、勘探、后续 | 降级 | `后续` 改为 `探索状态`，文案从“下一步”改为当前航点状态。 |
| HUD 任务追踪 | 当前目标、推荐任务、任务页入口 | 降级 | 保留首要任务摘要，不再用“下一步建议”命名。 |
| HUD 市场概览 | 本地三条市场信号、市场入口 | 保留 | 继续只显示摘要，不承载交易建议解释。 |
| 商业终端现货页 | 商品信号、成交按钮、行情图 | 降级 | “建议”统一改为“信号”，避免和行动条抢全局建议职责。 |
| 商业终端商网页 | 下一笔商网动作、站点策略、投资入口 | 保留 | 商网下一笔动作属于商业终端内部经营入口，继续保留。 |
| 星图详情 | 当前航点探索、卖货目标导航、航线风险 | 降级 | 保留当前星球相关行动；移除“下一步”字样和对行动条的解释。 |
| 机库派遣 | 自动贸易推荐路线、风险估算、派遣按钮 | 保留 | 派遣推荐属于机库内部执行前估算，保留。 |
| 机库改装 | 模块当前状态、升级项 | 降级 | 模块升级标签从“下一步”改为“可升级项”。 |

## 2. 删除 / 降级清单

- HUD 当前航点不再输出“下一步：轨道扫描 / 首次着陆 / 调查 POI”，改为“待扫描 / 待着陆 / 待调查”。
- HUD 任务追踪不再使用“下一步建议”，推荐模式改为“推荐任务”。
- 商业终端现货页不再提示“刷新主图、建议和右侧行动摘要”，改为只说明本地成交按钮。
- 星图 POI 列表不再把首个未调查点标为“下一步”，改为“优先”。
- 星图卖货目标提示不再说明“行动条会继续提示”，改为局部的抵达后处理说明。
- 机库模块升级区不再使用“下一步”标签。

## 3. 验收口径

- 同屏不会同时出现多个“下一步建议”来源。
- 行动条仍负责全局行动解释。
- HUD 保持摘要密度；市场、地图、机库只解释本页面直接可执行的动作。
- 业务规则、存档结构和系统计算不变。
