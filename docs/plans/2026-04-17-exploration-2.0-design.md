# 探索 2.0 设计

## 目标

当前探索 MVP 已具备 POI 调查和秘密航线解锁，但存在三个明显缺口：

1. 探索收益过于一次性，调查结束后很少影响后续决策。
2. 玩家很难在抵达后快速理解一颗星球“值不值得继续挖”。
3. 探索与贸易、研究、舰队补给之间的联系还不够强。

探索 2.0 的目标不是新增一套独立小游戏，而是在现有星球详情面板中加入“勘探报告系统”，让探索结果成为后续跑商、科研和补给决策的输入。

## 方案摘要

当前探索流程为抵达航点后直接调查 POI，不再设置额外的前置操作。

1. POI 调查。

在此基础上新增三层输出：

1. 探索简报：每颗星球拥有固定的威胁评级、机会焦点和完探奖励类型。
2. 调查结论：每次调查 POI 后，都会沉淀一条勘探报告，写入本地档案。
3. 完探奖励：当该星球全部 POI 调查完毕后，自动结算一次区域测绘奖励。

## 数据模型

探索状态仍保存在 `galaxyStates[planetId].exploration` 下，不新增顶层 save schema 字段。

新增字段：

- `intelLevel`：探索情报等级，随报告归档提升。
- `threatLevel` / `threatLabel`：星球勘探风险评级。
- `opportunityFocus` / `opportunityLabel`：该星球更偏向补给、贸易还是科研价值。
- `completionRewardKind` / `completionRewardLabel`：完探奖励类型与文案。
- `completionBonusClaimed`：是否已发放完探奖励。
- `completedDay`：完成区域测绘的天数。
- `reports`：勘探报告列表。

旧存档恢复时，默认 exploration 状态会自动补齐这些字段。

## 奖励设计

### 单个 POI 奖励

- 资源点：继续提供积分、燃料、声望，并额外产出“货运清单”报告。
- 异常点：继续提供高风险收益，但会额外产出“异常场剖面”报告。
- 航线信标：继续负责解锁秘密航线，并额外产出“暗线航图录入”报告。

### 完探奖励

当一颗星球所有 POI 都被调查后，自动发放：

- 基础奖励：积分 + 声望。
- 补给型星球：额外燃料与舰体整备。
- 贸易型星球：额外归档一条区域贸易综述。
- 科研型星球：额外归档研究线索，并在有当前研究项目时缩短 1 天研究时间。

## UI 设计

不新增页面，仅扩展现有星球详情面板的探索区块。

新增两个子区块：

1. 探索简报
   - 威胁评级
   - 机会焦点
   - 情报等级
   - 完探奖励

2. 调查结论
   - 按时间倒序展示当前星球已归档的勘探报告
   - 每条报告显示标题、类型标签和正文

## 与现有系统的关系

- 与贸易系统：探索报告会给出局部贸易窗口与出货方向提示。
- 与科研系统：科研型星球完探后可缩短当前研究项目时间。
- 与暗线系统：秘密航线仍是探索闭环的一部分，且报告会明确说明其长期价值。
- 与存档系统：继续复用 `GalaxyDataLayer.restorePlanetStates()` 的默认值合并逻辑。

## 测试重点

本次实现需要重点验证：

1. 新 exploration 字段能被旧存档正确补齐。
2. 调查 POI 后确实生成勘探报告并提升情报等级。
3. 全部 POI 完成后只结算一次完探奖励。
4. 科研型星球完探后会正确缩短当前研究时间。
5. 暗线解锁与 POI 奖励行为不回退。
