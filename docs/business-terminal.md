# 商业终端 (Business Terminal)

## 概述

商业终端是一个统一的全屏界面，整合了游戏中所有的商业、金融、和管理功能。它提供了现代化的终端风格设计，让玩家可以在一个界面中访问所有重要的商业操作。

## 功能模块

### 1. 仪表盘 (Dashboard)
- **核心指标**：资产总值、可用资金、贷款余额、信用评级等
- **贸易站日收益**：显示所有贸易站的每日被动收入
- **股票组合**：当前股票持仓的市值
- **期货盈亏**：未实现的期货盈亏
- **经济周期**：当前市场经济状态
- **舰队概况**：当前舰船信息、货舱使用、燃料状态
- **快速操作**：快速导航到各个功能模块

### 2. 市场 (Market)
- **公开市场**：合法商品的买卖交易
- **黑市交易**：非法/受限商品的交易（高风险高回报）
- **实时价格**：显示当前星系的买入价和卖出价
- **持仓信息**：显示每种商品的持有数量

### 3. 金融 (Finance)
- **银行贷款**
  - 查看可申请的贷款方案
  - 管理现有贷款（查看余额、剩余天数、日扣款）
  - 手动还款功能
- **股票市场**
  - 买卖股票
  - 查看持仓、成本、盈亏
  - 实时股价更新
- **保险服务**
  - 购买各类保险（船体、货物、舰队）
  - 提交理赔申请
  - 查看保额、保费、免赔额

### 4. 期货 (Futures)
- **期货合约交易**
  - 做多（预测价格上涨）
  - 做空（预测价格下跌）
- **持仓管理**
  - 查看开仓合约
  - 未实现盈亏实时计算
  - 提前平仓功能
- **历史记录**：查看近期成交的合约

### 5. 贸易站 (Stations)
- **网络概况**
  - 已建站点数量
  - 预计日收益
  - 累计收益
  - 管理员配置状态
- **站点管理**
  - 升级贸易站等级
  - 雇佣管理员（提升效率）
  - 设置经营策略
  - 查看每日收益和累计收益
- **建站候选**：在已访问的星球建立新贸易站

### 6. 舰队 (Fleet)
- **舰船列表**：查看所有拥有的舰船
- **舰船详情**
  - 货舱使用率
  - 燃料状态
  - 航速
- **舰船切换**：在不同舰船之间切换

## 如何访问

### 方法 1：底部导航栏
在游戏底部导航栏，点击 **TERMINAL** 按钮即可打开商业终端。

### 方法 2：快捷键（即将添加）
按 `T` 键快速打开/关闭商业终端。

## 界面操作

- **标签导航**：点击顶部标签切换不同模块
- **关闭**：点击右上角的 `✕` 按钮关闭终端
- **滚动**：内容区域支持滚动查看更多信息

## 数据更新

商业终端会实时同步游戏状态：
- 执行任何操作后，相关数据会立即更新
- 打开终端时显示最新数据
- 所有交易、金融操作都会立即反映在仪表盘上

## 集成功能

商业终端使用以下系统模块：
- `CommerceFacade.js` - 统一的商业操作接口
- `TradeSystem.js` - 贸易核心逻辑
- `FinanceSystem.js` - 金融服务（贷款、股票、保险）
- `FuturesSystem.js` - 期货市场
- `TradeStationSystem.js` - 贸易站管理
- `FleetSystem.js` - 舰队管理
- `Economy.js` - 价格计算和市场深度

## 技术实现

### 文件结构
```
js/ui/BusinessTerminalUI.js     # UI模块
css/business-terminal.css       # 样式文件
```

### 主要函数
- `init(state, callbacks)` - 初始化终端并注入回调
- `render(state)` - 根据当前状态渲染内容
- `show()` - 显示终端
- `hide()` - 隐藏终端
- `toggle()` - 切换显示状态

### 事件处理
所有操作通过回调函数连接到 `GameManager.js`：
- 市场操作 → `_handleOpenBuy`, `_handleOpenSell`
- 金融操作 → `_handleTakeLoan`, `_handleBuyStock`, 等
- 期货操作 → `_handleFuturesLong`, `_handleFuturesShort`, `_handleFuturesClose`
- 贸易站 → `_handleBuildStation`, `_handleUpgradeStation`, 等
- 舰队 → `_handleSwitchShip`

## 样式特点

- **终端风格**：深色背景，蓝色强调色
- **现代化设计**：卡片布局，渐变效果
- **响应式**：适配不同屏幕尺寸
- **动画效果**：流畅的过渡和悬停效果
- **可读性**：清晰的字体和配色
