# 开局一艘船，我成了星际首富 背景故事框架草案

玩家接手一家停业多年的小运输公司，从一艘起家轻舟和 1,000 CR 起步，在被大型航运公司放弃的星区经营商路。随着四座港口重新接通，一张没有签收的旧货单逐渐揭开断航往事，也让这家小公司找到了继续扩张的理由。

故事采用小人物创业逆袭的节奏：起步时不被看好，第一趟生意证明能够活下去，后续通过研发、开港和扩大运力做成别人放弃的市场。旧航路的调查贯穿成长过程，港口居民的生活变化给贸易提供具体意义。

本稿中的历史、人物和章节事件为新增设定。玩法衔接依据当前 2.2.0 的四港、四类货物、六种船型、百级公司和科技资格。当前已实现开场、首航回执、公司突破和首次开港的视频通讯引导，其余章内事件作为后续内容设计。

## 世界背景

### 旧航路的繁荣

过去，农业星球、矿业聚落和工业港口依靠一套公共导航与通讯设施往来。航标在星图上连成蓝色的线，人们把它称作蓝脉。

金穗农业星种植粮食，黑金矿星供应矿石，百炼工业星制造工具，聚宝原料星向工业区输送大宗原料。各地逐渐专注于自己的产业，商船负责把这些分散的生产能力接起来。蓝脉既是一条航运网络，也是许多偏远聚落赖以维持生产的联系。

### 断航与撤离

十多年前，一场强烈的恒星活动损坏了蓝脉的中继设施。公共航标失去校准，通讯断续，原有航线资料无法继续保证安全。各家运输公司先后停航，这段时期被当地人称为断航年。

灾害过后，中心航区逐渐恢复，大型航运公司的维修资金却优先投向吞吐量大、回收周期短的枢纽。外围港口被列入长期停服名单。没有稳定运输，港口的交易规模继续萎缩，维修评估又因此变得更差。

金穗农业星与黑金矿星依靠近域航标维持有限往来；百炼工业星靠当地材料和旧设备保持部分生产；聚宝原料星继续采集、储存原料，自动货站多年没有迎来常规商队。人们仍然生活和工作，只是越来越少有人相信旧航路会回来。

### 游戏开始时

最近，金穗农业星与黑金矿星之间的公共航标完成修复，小型运输公司的经营登记重新开放。两个港口已经具备贸易条件，外围航线仍需要重新勘察。

大型航运公司没有返回。这片市场的订单小、供需分散，对它们而言不值得重新组织大船队。对只有一艘轻舟的玩家而言，粮食和矿石之间的价差足够支撑第一笔生意。

## 玩家身份与动机

玩家是新登记的运输公司经营者，接手了曾经服务当地港口的蓝脉信使物流体留下的航运资产。交接时只剩一艘可用的起家轻舟、1,000 CR 和一份旧航运档案；玩家以新的公司名称重新起家，名称可随机生成或自由决定。

玩家的眼前目标是让公司正常运转，赚取利润，留下周转资金，并逐步买得起更多船。稳定经营后，再把目光投向新的货源和港口。

旧档案的末页夹着一张没有签收的货单：聚宝原料星发往百炼工业星的一批工业原料，状态停留在取消出航。原因栏写着公共航运服务终止，却没有解释为什么同一天另一些航区恢复了运输。

这张货单给玩家留下一个可持续追查的问题：那些被放弃的港口，后来怎么样了？找到答案也可能意味着找到下一条商路。

## 主线冲突

经营上的冲突来自有限的现金、运力和港口供需。玩家需要在扩船、研发、升级与勘察之间安排投入，建立能够持续盈利的商路。

人与人之间的冲突来自对外围市场的不同判断。老航运集团认为停服是控制成本的必要决定；当地经营者认为，这种判断忽略了小规模运输和重新组织贸易的可能。玩家用实际完成的航次回答这种分歧。

主线悬念围绕断航之后的停服决定展开。港口保存的记录逐步说明：最初的灾害确实无法避免，后来的长期失联却与资金分配、航线评估和责任推迟有关。每个环节都能给出自己的理由，结果是外围港口多年没有获得一次完整的恢复勘察。

| 百炼工业星 | 输出工具，购入矿石、粮食和工业原料 | 恢复三港贸易，并提供断航时期的生产与运输记录 | 仍在工作的车间旁有封存设备；档案中的停服日期与公共公告并不完全一致 |
| 聚宝原料星 | 输出工业原料，当前没有购入货物 | 远域开港与主线真相的主要地点 | 原料货场持续扩建，货运终端仍保存最后一批取消的出航预约 |

## 章节推进

章节顺序由经营成果推进。等级提供研发资格，完成研发、勘察返港或贸易结算才构成对应的故事节点。

### 序章 接手公司

梁简交出轻舟、账户和旧档案，告诉玩家近域航路已经开放。闻衡的评估意见认为，这片星区的交易规模不足以支持常规船队回归。玩家先从现有的粮食或矿石商路开始，准备货本，安排第一趟往返。

开场只交代公司处境、两个港口的需要和旧货单的悬念，完整历史留到后续章节。

### 第一章 第一张回执

**衔接范围：Lv.1起步、首航结算与首次升级。关键节点：首个盈利航次完整返港。**

首航的收货港确认到货，玩家获得第一笔实际到账的利润。旧公司的名称重新出现在采购记录里，梁简把新的回执放到没有签收的旧货单旁边。

首次升级至Lv.2后，梁简引导玩家分别研发船位规划与新港勘察，保留原船持续经营，再添购一艘轻舟用于探索。黑金矿星留下的旧班次记录显示，百炼工业星在断航后仍有生产和采购活动，引出下一座港口。

本章的成长感来自公司能够持续营业，以及客户开始期待下一趟船。

### 第二章 工厂仍在运转

**衔接条件：取得 Lv.2 的新港勘察与船位规划资格，分别研发、添购探索船，完成百炼工业星4分钟现场勘察并完整返港。**

玩家抵达百炼工业星后，发现当地仍然制造工具，却缺少稳定的矿石和粮食供应。岑遥保存着断航后的生产表、维修申请与被取消的采购单。

三港贸易开始恢复。第一批相关贸易完成后，岑遥提供一份停服复核记录：工厂所在航区曾具备修复条件，但申请因预计运量不足而延期。这让玩家第一次把灾害与后来的经营决定区分开来。

本章的转折是被外界视作衰落的工厂，仍然拥有可以交易的生产能力。

### 第三章 被低估的市场

**衔接范围：三港经营与 Lv.35 快速航路、Lv.52 重载物流等研发。**

工厂恢复供货后，两座近域港口也开始获得更多工具。唐禾关心持续到货，岑遥关心大宗采购，玩家逐步理解不同船型与商路的用途。

闻衡提出，过去的评估面向大型船队，零散订单确实无法覆盖它们的组织成本。玩家的经营记录说明，先以小船维持高周转，再按实际需求投入重载船，也能逐步建立市场。

岑遥从采购档案中找到聚宝原料星的旧呼号。远域货源成为公司下一阶段的机会，也与那张未签收的货单对应起来。

本章的逆袭感来自经营结果改变了别人对公司的判断。

### 第四章 最后一次取消出航

**衔接条件：百炼工业星已开放，取得 Lv.57 远域勘察资格，完成前置与研发，派船勘察聚宝原料星，现场勘察8分钟并完整返港。**

远域货站仍保存着多年采集的工业原料和出航记录。玩家在其中找到旧货单的另一份副本：那次运输没有遇到海盗或失事，而是在中心航区恢复服务的同一天，被取消了公共导航支持。

其后的复核持续沿用低运量结论。工厂因缺料削减生产，采购减少，又进一步降低了原料港的预计运量。双方的需要始终存在，但恢复运输的决定被反复推迟。

真相收束后，玩家建立聚宝原料星至百炼工业星的工业原料商路。第一趟真实贸易完整结算时，出现一张新回执，与序章的旧货单形成呼应。此次运输按当前货物、价格与货本经营，旧货单承担历史线索的作用。

本章的情绪落点是那条多年没有完成过的商路，终于有了新的到货记录。

### 第五章 商队成为新的常规航班

**衔接范围：Lv.71 联运调度及后续公司成长。阶段收束：四港开放，工业原料商路完成过实际结算，公司达到 Lv.100。**

公司的船队足以承担更多往返，四座港口开始把新的运输安排写进自己的生产和采购计划。闻衡在复核记录中承认，外围星区需要适合当地规模的经营方式；梁简则看到了旧公司重新成为一家能够持续履约的企业。

收尾场景回到公司档案：未签收的货单作为断航时期的记录保留，旁边是玩家建立的新商路回执。黑金矿星的值班表上，重新出现了固定的到港安排。

当前故事在四港贸易网络成形时收束，公司满级后继续经营。若以后扩展星区，可由一条未登记的远方呼号引出新篇章。

## 玩法与叙事衔接

| 当前玩法 | 对应的故事含义 |
| --- | --- |
| 自动往返与返港结算 | 商队逐步成为港口可以依赖的常规运输 |
| 独立货本与利润安排 | 公司必须有能力持续履约，扩张需要保留周转资金 |
| 供需等待与恢复 | 各港的生产和采购节奏影响运输安排 |
| 公司升级与每五级突破 | 组织规模、船位和承担更多业务的能力逐步提高 |
| 科技研发 | 从基础船体、报价与调度流程，逐步改善运输效率和远域经营能力 |
| 情报交易 | 取得星球身份、产业线索和勘察坐标；购买仍为可选投入，自然信号也能推动探索 |
| 勘察完整返港后开港 | 重新核验航迹、确认靠港条件，形成可以用于贸易的资料 |
| 六种经营船型 | 分别承担小额周转、常规运输、高频快递、重载和远距离经营 |

后续内容优先放在开场、港口详情、情报描述、核心研发完成提示和首次开港片段中。剧情围绕玩家已有的经营成果触发，阅读可以跳过，常规跑商持续执行。章末文字控制在短场景规模，避免每次升级都重复讲述同一段背景。

### 当前前期引导实现

序章交接弹窗显示实际公司名称、船只和资金，并展示旧货单线索。梁简以短通讯衔接首单、货本与完整返港；粮食送达黑金矿星并完成实际结算后，由唐禾留下首张回执，其他商路由梁简转交回执。查看报告后，通讯引导玩家用真实到账利润准备下一次投入。

自由经营阶段沿用单张下一步卡：第一次升级、Lv.2船位规划与新港勘察、添购空闲轻舟、去程与4分钟勘察、返港后第二条商路、五级突破使用不同通讯，闻衡只在突破评估时提出疑问。首次信号和勘察途中仍属第一章，勘察船完整返港后才由岑遥开启第二章。后续章节与更完整的档案内容仍按上方框架扩展。

四位角色使用统一风格的形象，在视频通讯画面中展示姓名、身份与信号标记；对白和当前经营目标并列，操作按钮作为玩家回应。开局、首航回执、突破评估和首次开港按上述真实进度切换角色。角色素材与生成提示词见 [通讯角色形象](../../assets/characters/README.md)。

所有节点由现有经营状态推导，剧情不发放额外资金或船位，也不替玩家支付研发、购船与探索费用。

## 游戏名称与定位

正式名称为《开局一艘船，我成了星际首富》。标题交代单船起步的低起点和经营逆袭的长期愿景，与接手小公司、逐步做大商队的主线衔接。

当前篇章以四座港口所在的星区为范围，故事随贸易网络成形收束，并为向更远航区扩张留下空间。蓝脉保留为世界中旧航运网络的称呼。
