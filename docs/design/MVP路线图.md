# 星际贸易商 - 一页优先级路线图

> 更新时间：2026-05-24
> 结论先行：当前版本已经完成“核心单机贸易经营版”和探索 / 行动引导 MVP，下一阶段不该继续平均补系统，而应把探索情报、科研、派遣、商网串成中期经营闭环。

---

## 1. 当前阶段判断

### 已经具备的主干能力

- 核心贸易闭环：买入 -> 航行 -> 卖出 -> 结算
- 动态经济：供需、价格历史、经济周期、黑市、走私检查
- 中期系统：金融、贸易站轻物流、舰队、船员、派系、科技、任务、成就、胜利
- 运行框架：3D 星图、商业终端、教程、行动引导、存档、测试基线
- 探索 MVP：扫描、首次着陆、POI、秘密航线、勘探报告和经营决策情报

### 当前最主要的缺口

- 探索深化不足：扫描、着陆、POI、秘密航线闭环已完成，但更复杂的遗迹链、隐藏区域、专属事件分支和经营联动仍未展开
- 中期行动引导不足：行动条已覆盖早期贸易 / 探索链，但金融、科研、派遣、商网还缺少上下文建议
- 飞船高阶玩法不足：没有战斗、乘客、外观、自定义职业化船型路线
- 剧情表达不足：已有轻量对话层，但章节推进和事件演出仍偏轻
- 平台能力未做：音频、i18n、云存档、多人都还在远期

### 当前研发判断

当前项目最接近：

**可玩的单机经营原型，正进入“中期经营闭环建设 + 架构收口”阶段。**

---

## 2. 优先级排序

## P0：稳态建设（立刻做，1-2 周）

目标：让当前版本可持续迭代，不再被文档口径、主控膨胀、破档和隐性回归拖慢。

对应 issue 清单：`docs/plans/2026-04-06-p0-stability-issues.md`

- 统一文档口径：README、路线图、实现对照表全部以当前 `js/` 结构为准
- 冻结 GameState / SaveEnvelope 契约：新增字段必须带默认值和迁移
- 建立最小回归集：优先覆盖存档、经济、派遣、金融/商网联动、任务推进
- 更新探索 / 行动引导口径：明确扫描、着陆、POI、秘密航线、行动条已经接入主流程
- 继续参数化：把经济、事件、任务节奏相关关键常量尽量收束到配置层
- 约束 `GameManager.js` 继续膨胀：新增中期动作前先定义 action handler 边界

完成标志：

- 改一个核心系统不会轻易破档
- 文档与代码口径一致
- 至少有一组稳定可重复的核心回归用例

## P1：体验深挖（接下来，2-4 周）

目标：让玩家在第一笔贸易和初次探索后，能自然进入科研、派遣、商网和公司成长。

- 行动引导二阶段：已补科研补给派遣预填、待处理事件、低燃料补给、维修 / 资金不足、商网投入 / 批量经营和资本侧贷款 / 股票 / 期货入口；继续补更完整的派遣策略
- 探索情报联动：勘探报告已能通过行动引导跳转市场情报区；后续继续影响科研补给路线、派遣评分、商网站点优先级
- 探索系统深化：基于已上线的扫描、着陆、POI、秘密航线闭环，继续补遗迹 / 异常点、基础奖励与风险、隐藏区域
- 飞船经营增强：加入维护成本、功能型改装、专长化船型定位
- 剧情表达升级：把关键章节、探索报告和派系事件接进轻量对话层

完成标志：

- 玩家除了跑商外，开始有“探索 -> 情报 -> 经营决策”的中期目标
- 不同飞船与船员组合出现更明确分工
- 章节推进有更强的叙事感和反馈感

## P2：中后期经营目标（随后，3-6 周）

目标：解决“系统很多，但后期目标不够强”的问题。

- 商网二阶段：轻物流首批已闭合站点分工、区域收益、勘探策略推荐和下一笔商网动作；后续再评估仓储、订单簿和更完整网络编排
- 公司成长二阶段：公司等级不只显示数值，要绑定权限、上限和特权
- 任务链扩展：派系线、商网线、探索线形成中长期路线差异
- 胜利条件再平衡：贸易、科技、外交、探索几条路径耗时更接近

完成标志：

- 中后期财富有稳定去处
- 玩家能形成自己的发展流派
- “商业帝国”从数值概念变成实际玩法目标

## P3：平台能力（后置）

目标：在核心单机体验稳定后，再投入高成本基础设施。

- 音效与音乐系统
- i18n / 文本外置 / 语言切换
- 云存档或更大容量存储
- 数据驱动工具链与内容编辑能力

完成标志：

- 游戏沉浸感和可扩展性显著上升
- 内容新增成本下降

## P4：网络化与社交化（远期）

目标：只有在单机版本稳住后，才考虑服务化和联网。

- 排行榜
- 异步社交或交易
- 多人同步框架
- 公会/聊天/共享市场

完成标志：

- 联网能力不会反过来拖垮单机主线开发

---

## 3. 明确不该现在做的事

- 不优先做多人：投入大、依赖多、对当前主线价值最低
- 不优先做完整 i18n：当前文本还在快速变化，先稳定内容结构
- 不优先做完整音频系统：应该放在主循环和中期体验补齐之后
- 不优先做大规模新系统堆叠：先把已有系统之间的接线、节奏和回归做扎实

---

## 4. 建议执行顺序

1. 先完成 P0：文档、契约、回归、遗留收口
2. 再进入 P1：行动引导二阶段 + 探索情报联动 + 飞船经营增强
3. 然后做 P2：公司/商网/任务线的中后期目标体系
4. 最后视资源推进 P3/P4：音频、i18n、云存档、多人

---

## 5. 一句话路线判断

这款游戏接下来最值钱的路线，不是“再补一个大系统”，而是：

**把探索获得的情报变成经营决策，把行动引导从新手链扩展到中期链，最后再做音频、国际化和联网。**
