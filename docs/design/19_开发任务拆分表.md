# 星际贸易商 - 开发任务拆分表

> 目的：将 [docs/design/18_实现线路图.md](docs/design/18_实现线路图.md) 进一步拆成可执行任务，直接对应当前仓库中的模块与文件。
> 使用方式：每一项都可以直接拆成 GitHub Issue、里程碑或开发卡片。

---

## 一、任务拆分原则

本表按以下维度组织：

- **阶段**：对应路线图中的阶段 A-G
- **任务**：一项可独立交付的工作
- **涉及文件**：优先列出现有文件，避免抽象描述
- **预期产出**：交付后应该新增或改变什么
- **验收标准**：如何判断这项工作完成

说明：

- 如果某项工作需要新增模块，也会优先说明应挂在哪个目录下。
- 如果某项工作暂不建议做，会在后文单列为“后置事项”。

## 九、建议直接立项的首批 Issue

如果现在就要开始开发，建议优先创建以下 10 个 issue：

1. 冻结 GameState 与 SaveEnvelope 契约
2. 补齐存档异常处理与迁移测试
3. 统一经济参数到 constants
4. 为事件系统补冷却/分层回归测试
5. 为商品增加合法性与品质字段
6. 实现黑市 MVP 与派系解锁联动
7. 自动贸易支持价格阈值和最低利润率
8. 设计并接入船员系统 MVP
9. 设计并接入贸易站系统 MVP
10. 新增 AudioManager 和设置项占位

## 十、后置事项

以下事项建议明确标记为“暂缓”：

- 完整实时多人
- 股票/基金/衍生品等金融系统
- 完整战斗系统
- 高复杂度拍卖行
- 全量多语言一次性接入

这些方向不是不做，而是不适合在当前阶段抢占核心开发资源。
