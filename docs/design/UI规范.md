# UI 规范

新增和调整界面时，复用共用样式与主题变量。本规范适用于当前经营界面。

## Loading 全屏适配

启动标题使用完整游戏名称，常规窗口按两句分行；横屏短窗口的恢复状态合为一行，为恢复与确认按钮保留空间。

启动和星图 Loading 共用全屏星空背景，内容直接在视口内居中，不套带边框、圆角或滚动条的卡片。内容不使用固定最大高度；窄屏和短屏分别收紧边距、图标、字号和段间距，避让设备安全区。星空与扫描线动画作为固定背景，不撑大内容的滚动区域。

普通加载状态不产生内外滚动条。失败恢复在短屏优先收起装饰信息，完整保留状态、重试、导出与确认操作；极端小窗口或大字号下，必要滚动由整屏承担，不再嵌套内部滚动区。保留键盘焦点和取消确认行为。

星图加载和失败提示覆盖资源栏、底部导航，防止短屏按钮被挡住；加载完成或返回经营后恢复主界面层级。现有设置对话框继续保持更高层级。

## 全屏页面背景

经营、船队、市场和报告页的星空渐变背景由全屏主容器 `#game-main` 统一承载，连续覆盖整个视口，包括内容边缘与底部导航后方。内容工作区及滚动区覆盖视口，保持透明，不设置外层背景、边框、圆角或投影。使用内容内边距避让资源栏、底部导航和设备安全区，避免在屏幕内部截断卡片阴影。功能卡片和弹窗继续使用各自的材质样式，星图使用自身的全屏渲染场景。

## 通用关闭按钮

弹窗、抽屉和详情面板的图标关闭按钮统一使用 `.ui-close-button`，放在标题栏右侧。

- 外形为正圆，宽高均为 **44px**，`border-radius: 50%`；桌面和手机保持同一尺寸。
- 关闭符号使用 `×`，字号 **22px**，水平、垂直居中；内边距为零。
- 按钮不得随标题或容器宽度收缩，标题换行时仍保持正圆。
- 使用中性深色材质、主题文字色与细边框；悬停时突出边框，键盘聚焦时显示清晰的焦点环。
- 使用原生 `<button type="button">`，设置具体的 `aria-label`，例如“关闭探索详情”。
- 保留所在面板的关闭逻辑、键盘操作和关闭后的焦点恢复行为。
- 新增通用关闭按钮必须复用此类。尺寸、形状和状态样式集中维护，单个面板不得另行覆盖。

```html
<button type="button" class="ui-close-button" aria-label="关闭探索详情">×</button>
```

共用实现位于 `css/merchant-material.css`，尺寸变量为 `--ui-close-button-size`。探索详情、港口详情、派遣配置、公司改名、设置已统一使用该样式。

“返回”“取消”等文字操作继续使用常规动作按钮；圆形规范用于图标关闭入口。

## 设置与系统页面

主界面资源栏右侧固定显示一个齿轮设置按钮，所有主页面和手机端均可见，一次点击直接打开设置。使用原生按钮、明确的“设置”标签和对话框关联，支持键盘打开；关闭设置或按 Escape 后，焦点回到打开入口。

资源栏保持 44px 基础高度并叠加顶部安全区。设置按钮使用 32×32px、18px 齿轮图标和 10px 圆角；上下内边距至少 5px，左右内边距至少 18px，并避让设备安全区。按钮垂直居中，使用轻微内阴影，悬停和键盘焦点保持可见，按钮与焦点环均不贴住资源栏边界。

设置使用统一的分页容器，当前包含“画面与声音”“存档”。存档管理只保留在设置的“存档”分页内，主界面不另设存档快捷按钮或工具下拉菜单。游戏名称与版本信息显示在设置底部。

后续同类系统管理、偏好和辅助页面整合到设置中，以新增分页扩展，复用现有设置布局、材质、状态提示及圆形关闭按钮，不增加同类主界面入口。分页在窄屏可换行，内容在设置容器内滚动，避免水平溢出。涉及覆盖、读取、删除或重新开始的操作保留游戏内确认。

## 公司名称

经营页公司名称使用粗体，常规字号为24px，窄屏为22px，前期紧凑面板为20px；长名称允许换行，避免挤压等级与经营信息。

公司改名从经营页的公司名称按钮直接打开独立二级弹窗。弹窗使用共用材质与圆形关闭按钮，显示名称输入框、“随机”“取消”“保存名称”，不放入设置分页。

新公司从 `js/data/companyNames.js` 的创业与星际航运主题名字库随机取名；已有存档保留原名。随机按钮只更新输入框草稿，每次避开当前输入值，保存后才修改公司名称并写入自动存档。名称可以手动输入，最多80个字符，保存时去掉首尾空格，不接受空白名称。

打开时选中当前名称，定时经营刷新保留草稿与焦点；取消、关闭、点击遮罩或按 Escape 均放弃草稿。Tab 焦点限制在弹窗内，关闭或保存后回到经营页的公司名称按钮。窄屏保留完整操作且无水平溢出。

## 提示条操作

经营操作结果（恢复进度、升级、研发、改名等）使用右上角的紧凑浮动提示，放在资源栏下方并避让安全区。提示不占经营内容的文档流，不拦截鼠标和触摸操作，约8秒后自动消失；长文案自动换行，窄屏不产生水平溢出。显示层级低于设置、改名与Loading，保留屏幕阅读器状态播报。

探索提示条的说明文字居左，操作按钮成组靠右，组内间距为 **8px**。桌面上文案与操作组并排；窄屏上文案在上、操作组在下，按钮仍靠右对齐。待探索、探索中和新港开放各状态使用同一布局。

## 前期剧情与经营引导

开场使用一次短交接弹窗，展示当前公司名称、实际飞船与可用资金，以未签收的旧货单引出后续探索。开始与跳过保持清晰，Escape 可跳过并恢复主界面焦点；旧档、已结束引导与刷新不重新播放。

首单、装船、首航与回款使用同一张引导卡，人物通讯保持一到两句，紧接当前经营目标与一个主要操作。首单按当前真实报价推荐商路，装船时提示进入派遣预估与确认；检查货本只聚焦已有输入，不清空草稿。返港时间来自在途航次，客户回执与到账净利只在实际结算后呈现。

完成或跳过后，已有“下一步经营”卡继续衔接公司升级、突破、船位研发与第二商路，不新增并列剧情面板。Lv.2说明船位规划、新港勘察的独立研发费用；先增加船位，再添购探索轻舟，原贸易继续运行。购船按钮只有备齐采购、探索费与必要货本后才可用；返港后的探索船可以直接投入第二条商路。首次信号与勘察通讯复用探索提示条，完整返港后才显示第二章与新港入口，未识别星球不提前透露名称或报价。

剧情阶段从原有引导、贸易、公司与探索状态推导，阅读与导航不改变资产。倒计时刷新不重建操作按钮，保留焦点和键盘操作。人物名称、章节和台词使用共用主题文字与材质；窄屏允许换行，操作保持可达且无水平溢出。

人物引导统一呈现视频通讯样式：角色形象、姓名和身份放在通讯画面中，章节与信号状态位于顶部，对话以字幕气泡呈现，操作区标注“你的回应”。开场使用较大的角色画面，经营与探索沿用紧凑通讯卡；窄屏让经营目标换到整行，保留角色与对白。角色形象来自本地素材，图片带明确替代文本；扫描线只作轻微装饰，系统减少动态效果或游戏关闭、减少动画时停用。

当前操作的引导选中框使用金色轮廓，每1.4秒柔和闪烁一次，只改变轮廓明暗。定时刷新保持同一目标的动画连续，切换步骤或跳过后移除旧框。目标获得焦点时保留静态轮廓；系统启用减少动态效果或游戏关闭、减少动画时同样使用静态轮廓。

## 星图详情与定位控件

探索详情打开时，隐藏右上角的“星图全景”定位按钮，关闭详情后自动恢复。详情的标题与圆形关闭按钮在面板滚动时保持可见，保留 Escape 关闭及关闭后的焦点恢复，避免背景控件与浮层边缘叠在一起。常规窗口将派遣操作固定在面板底部，短横屏通过面板滚动触达操作；无空闲船时提供“准备空闲船”，船坞未解锁则返回经营页的船位或购船引导。

## 探索与商路开放

派遣前分列往返飞行、现场勘察和预计总耗时，飞行包含去程、返程各一次。百炼工业星现场勘察4分钟，聚宝原料星8分钟；航速只影响飞行。过程中区分探索去程、勘察中、探索返港，显示本阶段剩余和总返港倒计时，勘察期间船停靠目标星球，刷新保留操作焦点。

新星球信号出现、探索去程、勘察及返港期间，市场、派遣、船型比较和报告均不展示该港口的商路或报价。港口详情、可选港口及新货物遵循同一开放条件，只有探索船完整返港后才开放；预先存在的市场或统计数据不能代替探索完成。

开港后，各界面同步更新。已打开的派遣面板同时更新商路按钮、港口与货物下拉选项，保留当前配置、货本和控件焦点。

## 市场情报

情报交易放在市场页内，桌面使用两列卡片，手机使用单列。未购买时只显示情报类型、线索摘要、交易等级与一次购买价格；获得情报后显示星球名称、资源线索、勘察条件和单独的探索费用。当前情报收藏与勘察获取共用展示，已获取的信息不重复出售。

已购星球线索允许提前查看身份和定性资源信息，不能据此显示未开港的供需数量、买卖报价、商路列表或派遣选项。情报只提供坐标；探索资格、占船、费用和完整返港条件继续适用。所有扣款经经营系统复核，余额或首航货本不足时禁用购买并说明原因。

购买完成在情报模块内反馈，并把焦点交给对应卡片标题。刷新和读档恢复收藏；定时更新保持控件与焦点稳定。已获得勘察资格时提供探索入口，完整返港后改为新港商路入口；尚未具备资格时说明下一步条件。

## 科技研发

经营调度的第二页签统一为“科技研发”，与“航运任务”保持相同宽度和材质。支持方向键、Home/End、可见焦点和选中状态；定时刷新不切换页签、不重建未变化的按钮。

科技卡展示全部项目，按公司Lv.1–100 顺序排列，标明类型、效果、等级、前置、一次研发费用和状态。未到等级、未完成前置、现金不足或触及首航货本储备时禁用操作并说明原因。研发完成后保留完整卡片、原位置和原尺寸，显示绿色“已研发”标签，原研发按钮保留尺寸并改为禁用的“已研发”；名称、效果和前后置关系仍可查看。完成不移动其他节点、不改变线路几何或画布尺寸、不收缩整块研发区域，滚动位置保留，焦点交给当前卡片的科技名称。完成进度与累计加成继续更新。分类按钮统计完整项目数量，列表状态分别列出总数、已研发和待研发数量；一类或全部科技完成后仍保留对应的完整卡片。

公司共100级，每个5级阶段开放2–5项研发，共65项。各个项目各自支付费用并检查前置，不要求再次升级公司。属性科技每项只增加 1%–4%，卡片说明本次增量，顶部汇总累计效果；载量继续按整舱位取整。船队扩容每项增加 1–2 个船位，以整数显示，与船只载货量的百分比区分。公司面板与发展路线同时显示新增项目数量和完整名称，避免只展示本级第一项科技。

航运科技作为公司经营页内的一种研发类型，包含基础船体及进阶船型解锁。类型筛选使用原生按钮组，提供“全部”“航运科技”“航速”“载量”“收益”“船队扩容”“功能”，以 `aria-pressed` 表示选中类型，并反馈当前展示数量。选中按钮使用共用强调色渐变与反色文字，悬停和键盘焦点保留选中材质。筛选结果保持等级顺序，筛选按钮保留原节点、键盘焦点和当前选择；切换页面、定时刷新和研发完成均使用同一分类状态。手机端按钮组换行，保持 44px 点击高度。

科研报价按科技所属等级的公司普通费用基数、每5级阶段N系数、效果权重及核心系数计算，显示一次性完整金额；公司升级只开放资格。报价、现金不足与首航货本提示、前期勘察资金目标和船型投资比较共用实际研发费用。已有科研成果不补扣费用。

顶部汇总航速、载量、商路净利与船位累计加成。船坞、船型比较、派遣船只和满载货本同步显示实际加成后的数值。在途进度与结算继续展示出发时锁定的值。科技树按每5级一段从上往下延伸，桌面按可用宽度排列三列或两列分支，手机只保留一列；阶段与节点均不向右扩展，画布无横向滚动。节点位置由完整科技表确定，分类筛选和研发完成不移动其余节点。同阶段的依赖也必须在更低一行。船坞只保留船队、采购与投资比较，不再重复放置研发区域。

相邻科技使用向下短线，同列直连，跨列在卡片与前置入口以外的空隙转折。远端或被分类筛选隐藏的来源，合并为目标上方44px高的具名前置入口，再用短箭头进入目标；来源名称与完成标记保留，点击入口展开详情并可定位来源，包括已研发科技。完成科研只更新连接状态，不把原来的完整节点替换成缩小引用。多前置完整列出，全部完成才可研发。选中科技仅突出直接前置与直接后续，普通线路保持弱化；不把整片上下游同时标为选中路径，也不画贯穿许多阶段的长线。线路不得穿过科技卡片或前置入口，不在边缘堆叠长竖线。

科技树提供阶段选择、上一阶段/下一阶段、当前阶段和下个核心定位。上下方向键滚动画布，Home/End 跳到首末阶段；手动滚动同步阶段选择。点击科技名称查看完整前置、后续项目与剩余前置费用。点击关系中的项目直接定位，跨类型时切回全部，定位也让画布出现在资源条下方，同时保留目标上方的前置入口。桌面详情放在右侧，窄屏放在画布下方；点击前置入口时将焦点交给关系标题，并保证详情出现在资源条与底部导航之间。研发费与前置链费用分开说明。8个核心节点使用金色标记和更高研发费用，保留单项小幅效果。已研发卡片与详情保留核心标记，关系中的完成来源标明“已研发”，仍允许定位，不重新收费。

## 公司逐级升级与突破

公司面板显示当前阶数，只提供当前等级到下一级的升级或突破操作，明确显示“Lv.当前 → Lv.下一级 · 每次提升 1 级”及本次费用；公司共100级，每5级一阶。发展路线只渲染当前阶的5级，突破后替换为下一阶的5级，仅供查看，不提供跨级或升至最高级的操作。主面板与前期成长提示使用同一费用和逐级校验，旧等级重复提交不得继续扣款。

发展路线每级分为等级栏、效果区和待达成费用区。等级标签在左，右侧同一行显示“已达成”“当前”或“未达成”状态标签，分别使用完成色、强调色和次要文字色；状态不放在效果区底部。等级栏和效果区以背景与分隔线区分，效果区列出船位、研发资格与突破关卡；尚未达到的等级在底部分开显示升至此级的费用。桌面五列，中等宽度三列，手机两列，等级与状态不得挤压或换行，内容无水平溢出。

等级说明只显示实际新增的基础船位、科技研发资格及突破关卡。没有新增船位或科研资格的等级保留等级、船位与费用，不填“公司成长”“积累等级”等占位文案；下一级无新增内容也不是突破关卡时不显示预告。科技名称标明“开放研发资格”，完成付费研发后效果才生效。升级反馈和前期提示同步遵循此规则。

船位显示实际总上限，并拆出“基础船位 + 研发船位”。下一级预告只计算当前已完成的扩容，不提前计入待研发船位；路线图分别标明基础和完成扩容后的上限。满级仍有扩容可研发时显示剩余可增加的船位。前期紧凑面板保留船位来源，控制手机首屏高度。平衡调整后旧档船数超过当前上限时，显示“超出上限 X 艘 · 现有船只保留”；已有船与任务继续运行，采购按钮保持禁用直到获得空余船位。

Lv.5、10…95达到突破关卡时，升级按钮改为“突破公司至Lv.下一等级”，显示进入本阶第五级的普通费用、N系数和本次突破总价。N从2开始，每次突破增加0.5；突破成功后等级只增加1，切换阶段并恢复普通升级按钮。Lv.100是满级，不再突破。

资金不足或触及首航货本时禁用升级或突破并显示原因，满级显示禁用的“最高等级”。升级后刷新当前等级、下一级费用和研发资格，键盘焦点交给可用的新升级按钮；不能继续升级时交给当前等级标记。窄屏保留完整费用、等级和原因，不产生水平溢出。
