# 蓝脉航路 2.0

当前版本：**2.0.0**。主玩法是经营自动跑商的商队：创建经营派遣，通过任务列表管理船只、货本与经营成果。

新局用简短开场与最多五步软引导认识首次派遣和返港报告，可随时跳过，不额外发奖励；旧档不重播。

无法继续的任务自动解除，有效航次返港结算后释放预算和船只；市场恢复后由玩家重新派遣。公司二级后可在星图发现信号、派空闲船完成勘察往返来开放新商路，不额外发船或 CR。成长模拟采用真实探索与每秒主动检查、补派策略，不是离线持续收益。
