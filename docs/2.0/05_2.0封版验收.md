# 2.0 封版验收

版本：**2.0.0**，存档结构：**v26**。范围是商队经营、公司成长与已确认的场景及界面。旧内容已从产品目录移除，清理前完整备份位于项目外。

本轮新增简短开场和最多五步软引导，使用 v26 保存进度，新局可开始或随时跳过，旧档标为完成不弹出。软引导实际新局流程、刷新持久性、代码检查、23 文件 158 项全量测试与生产构建均已通过；此前探索、自动解除、科技、星图与界面记录保留原范围，不代替新引导验收。发布归档与文件哈希以重新封存后的清单和校验结果为准。

## 当前交付范围

保留经营任务、简短开场与软引导、独立的新港探索、六种经营船型、三项航运科技、六级公司、市场、报告、星图、音效、设置、手动存档、恢复页和当前原创建模源。经营日志页面与入口已移除，“更多”只保留设置和存档图标。

## 本轮规则与界面

- 前期最多五步含开场：开始或跳过、选择商路、配船与货本并真实出航、首笔返港后查看报告、了解利润发展方向并主动结束。全程自由操作、随时跳过，不锁其他按钮，不要求逐笔展开报告或攒够 1,800 CR。
- 引导不赠 CR 或船、不加速，也不提前开放等级功能。失败或零航次派遣不完成真实出航和返港步骤；后台与自动解除规则不变。`merchant.onboarding` 保存 0–5 的步骤与跳过状态；低于 v26 的旧进度一律标完成，v25 原始字节另存 `before_v26` 备份。
- 出航失败后按完整任务预算与当前供需重算分配船，无盈利航次则整任务停止新航次；有效在途航次继续完整往返且只在返港结算一次，最后释放预算与船只。没有在途航次时立即结束并全退预算；只有同任务在途货本暂被占用且完整预算和供需仍能盈利时等待回款。
- 待生效调整先安全应用再检查；停止时取消调整，释放仅为调整新增的预留船。可选 `stopReason` 兼容旧存档，不重置资产；列表简写“自动解除 · 等待返港”，原因在详情与已结束报告保留，零航次/零利润也留记录。市场恢复后须重新派遣。
- 公司等级为成长主线，六级船位总上限为 4 / 8 / 14 / 22 / 32 / 48 艘；升至二至六级分别支付 1,800 / 4,000 / 9,000 / 18,000 / 36,000 CR。后续每级费用约翻倍，避免三港经营成形后连续快速升级；空闲、等待和在途船都计入总数，升级只扩容并开放资格，不赠送飞船。存档已达等级及资产继续保留，不重算或补扣此前升级费用。
- 新局一级可使用经营、星图和报告，并在派遣内购买三种基础船。二级开放船只与市场页面、新港探索资格；在 30–90 秒随机信号出现后，玩家选择已开放源港和空闲船，支付 360 CR 并保留首航本钱。去程、30 秒勘察及返程完成后才开放星云工厂商路，不赠船或额外 CR。信号与时间轴持久保存，刷新不重抽；探索全程排他占船，离线可完成已开始航次，旧直接开港命令拒绝。未开放入口隐藏，星图始终位于正中间；迁移存档已开港或已研发科技对应的页面入口继续保留。
- 快速航路、重载物流和联运调度分别在三级、四级和五级开放研发；费用为 3,000 / 9,000 / 27,000 CR，按三倍梯度递增，联运调度仍须完成前两项科技。三项科技一一解锁流星快递舰、巨帆散货舰、远航联运舰的可购资格，不赠船，购买另付逐艘报价；未研发的进阶船不显示采购卡或派遣添购项。已研发状态和已有船只保留，不追扣历史费用。
- 各船型独立按已持有同型船数递增购价：下一艘为向上取整（基础购价 × 1.2^已持有同型船数）。六种基础购价保持 280 / 340 / 560 / 850 / 980 / 1,250 CR；赠送船、旧档船及空闲、等待、在途船全部计入。批量按连续序号逐艘取整后求和，合单与拆单同价。新局已有一艘轻舟，后续报价为 336 / 404 / 484 CR，一次购买两艘合计 740 CR；首艘快船 340 CR，第二艘 408 CR。既有船只不追扣购价。
- 自由现金单独显示在最上方 CR 资源栏。公司名称、等级、持有量/总上限、空余船位、下级目标、费用/升级按钮与发展路线集中在经营页同一模块，不重复任务数或在途数；船只页不展示公司信息。设置与存档入口只显示图标，保留可访问名称、提示与键盘操作。
- 经营页标题、任务详情、派遣成功反馈和在途船只行不再提供星图跳转按钮，星图统一由底部导航进入。
- 新派遣商路与市场共用可执行性判断及稳定排序：可派遣商路在前，暂不可派遣商路在后，各组内部保持原顺序。资金、供需或运力变化时刷新商路按钮，保留已选商路、船只与货本；后排商路仍可选择查看条件。
- 航运任务卡统一由外层显示选中边框与左侧强调线，内层点击区域保持透明、继承圆角且不浮起，悬停不遮挡高亮。派遣的飞船勾选使用深色原生勾选框，整卡随实时选择显示主题边框与柔和底色，键盘焦点分别在任务卡内侧与飞船整卡显示。
- 公司模块与航路场景保留 24 px 间距，窄屏为 20 px；采购数量框与购买按钮共用 44 px 高度。按钮按真实条件显示金色可执行、灰色条件不足、绿色已完成、琥珀色等待和红色结束/删除状态，保留纹理、提示与禁用校验；这些语义颜色不随星系变化。
- 船坞与派遣添购的数量控件隐藏原生上下步进按钮，数字居中，由玩家直接输入；保留 1–20 艘整数校验及购买金额即时更新。
- 主页面、资源栏、导航、设置、存档与加载界面按各自容器局部垂直居中；多行信息整组对齐，公司费用与 CR、任务标题与数量保留不同字号的行内对齐。派遣输入为 40 px 高、采购控件为 44 px 高，长文字继续换行或滚动。船卡在不超过 1,100 px 时两列、不超过 760 px 时单列；报告逐笔详情保留最高 360 px 的滚动区域，手机收入信息独占整行。
