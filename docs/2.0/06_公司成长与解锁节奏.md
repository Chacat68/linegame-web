# 公司成长与解锁节奏

公司等级是经营成长主线。玩家先跑通贸易循环，再用净利润在公司扩容、派船探索、购船、研发与货本之间取舍。升级不自动执行；公司开放资格后，新港仍需投入 CR 和暂时退出经营的船只完成探索，科技仍须支付研发费用。基础派遣、调整、停用、报告与存档从一级就能操作。

## 等级与内容

| 等级 | 总船位 | 升到该级 / CR | 内容和新的经营问题 |
| --- | ---: | ---: | --- |
| Lv.1 | 4 | 初始 | 两港、派遣内三种基础船采购、星图与报告：先选择货物、船型与周转货本 |
| Lv.2 | 8 | 1,800 | 船坞与市场页面、第三港探索资格：先暂停一艘经营船去探索，还是继续扩大两港运力 |
| Lv.3 | 14 | 4,000 | 可研究快速航路：研发与现有任务投入怎样分配 |
| Lv.4 | 22 | 9,000 | 可研究重载物流：大船需要更充分的货本与需求 |
| Lv.5 | 32 | 18,000 | 可研究联运调度：先补齐前置科技还是继续存钱 |
| Lv.6 | 48 | 36,000 | 当前规模目标：继续优化商路组合，无额外隐藏功能 |

一级只显示经营、星图与报告导航，基础船可直接在派遣内批量购买；二级再开放独立船坞和市场页面，星图保持导航正中间。未开放的入口和科技功能不显示。新港探索资格到二级开放，30–90 秒后出现未开放星云工厂的信号；玩家选择已开放源港和空闲船，另付 360 CR，完成去程、30 秒勘察与返程后才开放商路。探索占用的船不能同时经营，无新船或额外 CR 奖励。随机状态和信号时点保存在进度中，刷新不重抽。快速航路研发 3,000 CR、重载物流 9,000 CR、联运调度 27,000 CR，后者须先完成前两项。每项科技仅开放一种船型的可购资格，依次为流星快递舰、巨帆散货舰、远航联运舰；研发不赠船，船价、首航货本和持有上限继续独立检查。

科技费用按三倍梯度递增，在公司三级、四级和五级取得资格后仍需积累研发资金。研发、公司升级、购船与货本继续争用自由现金，进阶船还要另付逐艘购价；达到公司等级不等于已经取得对应船型。已研发科技保留且不追扣，新费用仅用于后续研发。

## 初期经济依据

新局 1,000 CR 与一艘轻舟。首次公司升级为 1,800 CR，不能直接用开局资金跳过一级经营。后续升级费用逐级约翻倍，让二级投入三港网络后仍需积累，避免利润增加后快速连续升级；购船、研发和存钱升级继续争用自由现金。全部费用只从自由现金支付，任务预算继续用于自动周转，净利润不自动复投。

购船成本也随同型持有量增长：下一艘为向上取整（基础购价 × 1.2^已持有同型船数），赠送船、旧档船及空闲、等待、在途船全部计入，各船型独立计算。基础购价保持 280 / 340 / 560 / 850 / 980 / 1,250 CR；批量逐艘取整后求和，与拆单同价。新局的下一艘轻舟需 336 CR，再一艘需 404 CR，两艘合计 740 CR；首艘快船仍为 340 CR，第二艘增至 408 CR。同型扩船逐渐占用更多资金，但不改变载量、航速、往返费用或公司升级成本。已有船只不追扣购价，新报价只影响后续采购。

现有货物固定买卖价、60 秒补货和完整往返费用决定每一航次的利润。初始轻舟可选择粮食路线的 126 CR 货本，或矿石路线的 162 CR 货本；双船参考配置分别使用快船粮食 178 CR 和轻舟矿石 162 CR，部署后剩余自由现金 320 CR。无货、需求耗尽或完整预算无法盈利时任务自动解除，不能把市场恢复后的收益当成原任务持续循环的收入。

供需会限制扩船收益，不能把单船首轮利润简单乘以船数和离线时长。公司船位是持有许可，不是自动收入倍率。

单船与多船的升级节奏还取决于玩家何时查看市场并重新派遣。先前等待恢复规则下的单船时点与稳定每分钟收益不再作为当前成长依据。

## 主动补派与探索参考路线

运行 `npm run simulate:growth`。模拟从真实开局状态出发，花 340 CR 买首艘快船建立双港两船；二级后等待探索信号，在资金可支持探索及三港投入、初始轻舟仍有有效航次时停止其经营任务并等船返港，再从已开放港口派船探索星云工厂。探索全程排他占用该船，不能派贸易；返港开放新港后才购入第二艘快船并投入三港三船。

脚本使用固定随机种子保证同一输入可复现，可通过 `--seed=<整数>` 指定。每秒模拟玩家检查供需，对已结束路线仅在盈利且货本足额时用空闲原船创建新任务，并在升级与研发时保留待补派货本。游戏本身不会自动派船探索或补派；结果是主动经营参考，不是纯挂机、无人值守或离线持续收入。

三港扩张按实时状态累计投入：探索 360 CR、第二艘快船当前报价 408 CR、新任务货本 238 CR、初始轻舟返港释放后新工具路线的 260 CR 货本、其他待补派货本及 100 CR 策略缓冲。等待信号、停用任务、返港与勘察都消耗时间，探索期间原船没有贸易收入；不能把费用支付视为已经开港，或沿用直接付费开港时的成长时点。缓冲只属于模拟策略，不是额外费用或玩家必需条件。

2026-10-04 已按真实探索接口实跑，默认种子为 42，两模式均返回 `completed: true`。公司二级在 14.37 分钟达成，信号在 14.87 分钟出现；策略继续积累三港投入，在 28.02 分钟停止轻舟经营任务，等待 17 秒返港后于 28.30 分钟探索出发。主星出发的单程为 15.429 秒，含勘察的完整往返为 60.858 秒，在 29.31 分钟完成开放，29.32 分钟投入新商路。

## 科技投资参考策略

使用 `npm run simulate:growth -- --with-research` 对比同一探索与主动补派策略：在三级、四级、五级先完成当级科技，再继续存钱升级公司，不采购进阶船；每秒检查、盈利补派及货本保留规则相同。

三项研发费用分别为 3,000 / 9,000 / 27,000 CR，合计 39,000 CR；联运调度须先完成前两项。在固定三艘基础船的条件下比较研究支出的资金机会成本，不推导购买并派遣进阶船后的收益或统一通关时间。默认种子 42 的实际结果如下，两模式均完成至六级：

## 内容边界

当前内容只有三港，五级时现有新港探索与科技资格均已开放，六级只提供规模目标。不能用六级数量替代未来商圈内容，也不能据此宣称已验证数周成长曲线。上述成本和容量先作为可运行、可调整的首版参数，之后结合试玩中的自动解除频率、补派间隔、探索占用、现金去向和升级间隔校准。

现有存档的等级和资产不因价格调整重新计算，不追扣已完成升级的费用；新价格只用于下一次升级。旧存档补入公司等级时保留所有船、已开港、科技、任务和账目，也保留对应市场与船坞入口；超出初始上限也不删船，只限制新购。升级界面和发展路线只在经营页，船只页保持采购与船型信息的聚焦。
