# 开局一艘船，我成了星际首富 2.2.0

本版整合早期2.1发布包之后的公司成长、科技树、市场情报、经营调度与界面调整。游戏版本2.2.0，存档结构v34，历史2.0.0与2.1.0发布包继续保留。

## 公司与科技

- 公司增加至100级，Lv.5、10…95触发突破，Lv.100满级；升级和突破均只增加一级。发展路线只展示当前阶的5级，等级状态标签位于等级右侧，解锁效果单独分区。
- Lv.1基础船位为1个，Lv.100为30个；11项扩容科技另增加15个船位。公司与科研价格根据每阶段最大船队、共享供需净利及独立投入校准。
- 经营方案移除，经营页的第二分页改为科技研发。65项科技分为航运科技、航速、载量、收益、船队扩容及功能；公司等级开放资格，完成所有前置并付费后才获得能力。
- 科技树按20个五级阶段向下延伸，桌面分列、手机单列。相邻节点用短线连接，远端或筛选隐藏来源用具名前置入口，选中科技仅突出直接前后置。
- 8项核心科技提高成本。单次属性提升为1%–4%，船型研发、购船、扩容和探索分别付费；全部科研合计9,370,700 CR。
- 科技研发完成后保留原尺寸、原位置、原连线与完整内容，标记“已研发”；全部完成后仍保留完整科技树，分类总数稳定并分别显示已研发与待研发数量。

## 经营与界面

- 市场增加可付费购买的星球情报，购买后提供信号与信息；探索完整返港前，各界面均不开放新港商路。
- 航运任务集中展示多船航段进度、货本、结算、调整与结束操作。暂时缺货或需求满时保留任务，供需恢复后自动续跑。
- Lv.2可分别付费研发船位规划（1,300 CR）与新港勘察（2,100 CR），均无中期前置。引导先增加1个船位，再添购空闲轻舟，原商路持续经营；新船完成去程、4分钟现场勘察及返程后开放百炼工业星，并以返港船开启第二条商路。首次现场勘察4分钟，后续原料星8分钟，总耗时另计两段飞行。
- 前期剧情由梁简的公司交接和旧货单线索开始，实际首航结算后收到客户回执。单张引导卡衔接升级、突破、扩容与首次勘察，完整勘察返港后由岑遥开启第二章；可随时跳过，读档不重播。
- 设置由资源栏齿轮直接打开，存档并入设置分页。全屏背景铺满页面，通用关闭按钮统一44px正圆，探索面板避让定位按钮。
- 公司名称直接打开独立改名弹窗，支持手动输入与随机换名；新局从48个主题名称中随机取名，已有存档保留原名。随机只修改草稿，保存后写入自动存档。
- 启动与星图Loading适配横竖屏和短窗口，恢复提示、确认按钮与错误返回保留键盘焦点；加载层等待真实首帧后退场。

## 存档与规则记录

v34旧档迁移保留现有现金、船只、港口、科研成果、任务与货本。旧档科研不重复收费，不补造历史收益，不改变在途航次的时间或金额；新效果从下一次出发应用。探索记录出发时的现场勘察时长；旧档已派出或完成的探索保留30/60秒旧计时，待派出信号使用4/8分钟新规则，v33原文另存`startrader_save_before_v34_槽位`。
