# 蓝脉航路 2.2.0

本版整合早期2.1发布包之后的公司成长、科技树、市场情报、经营调度与界面调整。游戏版本2.2.0，存档结构v33，历史2.0.0与2.1.0发布包继续保留。

## 公司与科技

- 公司增加至100级，Lv.5、10…95触发突破，Lv.100满级；升级和突破均只增加一级。发展路线只展示当前阶的5级，等级状态标签位于等级右侧，解锁效果单独分区。
- Lv.1基础船位为1个，Lv.100为30个；11项扩容科技另增加15个船位。公司与科研价格根据每阶段最大船队、共享供需净利及独立投入校准。
- 经营方案移除，经营页的第二分页改为科技研发。65项科技分为航运科技、航速、载量、收益、船队扩容及功能；公司等级开放资格，完成所有前置并付费后才获得能力。
- 科技树按20个五级阶段向下延伸，桌面分列、手机单列。相邻节点用短线连接，远端或筛选隐藏来源用具名前置入口，选中科技仅突出直接前后置。
- 8项核心科技提高成本。单次属性提升为1%–4%，船型研发、购船、扩容和探索分别付费；全部科研合计9,389,600 CR。
- 科技研发完成后保留原尺寸、原位置、原连线与完整内容，标记“已研发”；全部完成后仍保留完整科技树，分类总数稳定并分别显示已研发与待研发数量。

## 经营与界面

- 市场增加可付费购买的星球情报，购买后提供信号与信息；探索完整返港前，各界面均不开放新港商路。
- 航运任务集中展示多船航段进度、货本、结算、调整与结束操作。暂时缺货或需求满时保留任务，供需恢复后自动续跑。
- 前期从一艘轻舟开始，通过真实贸易积累、逐级升级、支付完整科研前置链、购船与探索推进。
- 设置由资源栏齿轮直接打开，存档并入设置分页。全屏背景铺满页面，通用关闭按钮统一44px正圆，探索面板避让定位按钮。
- 启动与星图Loading适配横竖屏和短窗口，恢复提示、确认按钮与错误返回保留键盘焦点；加载层等待真实首帧后退场。

## 存档与规则记录

v33旧档迁移保留现有现金、船只、港口、科研成果、任务与货本。旧档科研不重复收费，不补造历史收益，不改变在途航次的时间或金额；新效果从下一次出发应用。
