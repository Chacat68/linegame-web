# 开局一艘船，我成了星际首富 2.2.0 发布包运行说明

更名前封存的 `blue-meridian-2.2.0.zip` 包含静态游戏和版本文档，保留当时的《蓝脉航路》名称；当前工作区使用《开局一艘船，我成了星际首富》。解压后在包目录执行：

```sh
python3 -m http.server 4180 --directory game
```

打开 `http://localhost:4180/`。游戏通过 HTTP 运行，避免直接双击 `game/index.html`。

浏览器存档按地址与端口隔离。切换到发布包前，可在原游戏的“设置 → 存档”导出 JSON，再从新地址导入；继续使用原地址无需手动转换。

本版将百级公司、五级突破、65项纵向科技树、市场情报、船队扩容及前期经营调整整合封存。公司升级与突破均只提升一级，价格依据各阶段最大船队收益递增。公司等级开放研发资格，科技须完成全部前置并独立付费；8项核心科技设置更高费用。已研发卡片保留原尺寸、原位置与完整内容，显示“已研发”。

经营方案已移除，科技研发在公司经营内按六类筛选，船只页保留采购和投资比较。新星球只有探索完整返港后才开放商路。设置从资源栏直接打开，存档统一在设置分页内；关闭按钮采用44px正圆。全屏页面背景、Loading横竖屏与短窗口适配已调整。

存档结构为v33，旧公司等级按原科技资格迁移；保留原现金、船只、港口、科研成果、货本与在途快照。旧档已付费的科技不补扣费用，不自动赠船。新局软引导可跳过，旧档不重播。

项目内的 `npm run check:release` 检查当前源文件、构建物与 ZIP。`blue-meridian-2.2.0.zip.sha256` 为 ZIP 校验值，在本目录执行 `shasum -a 256 -c blue-meridian-2.2.0.zip.sha256` 可单独验证。2.0.0和早期2.1.0清单与 ZIP 保留为历史快照。

版本说明与测试记录见 `docs/2.2/README.md`；详细规则、经济模拟与历史验收保留在 `docs/2.1/`。模拟是实际规则下的固定策略对照，不代表最优策略或离线收益。
