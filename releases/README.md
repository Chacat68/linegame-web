# 蓝脉航路 2.0.0 本地发布包

`blue-meridian-2.0.0.zip` 包含静态游戏和当前文档。解压后在包目录执行：

```sh
python3 -m http.server 4180 --directory game
```

打开 `http://localhost:4180/`。需要通过 HTTP 运行，请不要直接双击 `game/index.html`。

浏览器存档按地址与端口隔离。从原来的 4173 入口切换到发布包时，可先在原游戏“更多 → 存档”导出 JSON，再从新地址导入。“更多”中的齿轮和磁盘图标分别打开设置与存档。继续使用原地址无需手动转换。

项目内的 `npm run check:release` 检查封版源代码、构建物和 ZIP。`.sha256` 是 ZIP 校验值；在本目录执行 `shasum -a 256 -c blue-meridian-2.0.0.zip.sha256` 可单独验证归档。

该包只包含当前三港商圈及商队经营，不含已退出玩法、浏览器存档或清理前备份。新港通过公司二级后发现信号并派船探索开放，支付 360 CR、完成勘察往返后才提供商路，不赠船或额外 CR。存档结构为 v26，原来已开放的港口继续保留。收益参数是 2.0.0 基线；长期平衡与新商圈通过后续版本调整。

新局提供简短开场与最多五步软引导，可随时跳过，不锁其他按钮、不赠资金或船、不加速。旧存档的引导标为完成，v25 原始内容另存备份，不重新弹出。

经营条件不再支持盈利时，任务自动解除，有效在途航次完整返港后结算并释放预算与船只；无在途航次则立即结束。已结束任务不随市场补货自动恢复，需由玩家重新派遣。文档中的成长模拟执行真实返港探索，并使用每秒主动检查和补派策略，不是发布包的自动或离线经营承诺。
